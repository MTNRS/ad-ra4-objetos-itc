# Prácticas de la unidad

1. Persistir Cliente como objeto simple sin proyectos.
2. Persistir un Cliente estructurado con proyectos anidados.
3. Buscar por nombre y modificar estado.
4. Provocar identificadores duplicados y comprobar rollback.
5. Importar tablas de SQLite y reconstruir los objetos relacionados.

Referencia: unidad 004 de Acceso a Datos, persistencia, API de acceso,
transacciones y desarrollo de programas que gestionan objetos.
